# Finish Protocol Specification

## Purpose

Определяет фиксацию финиша участников, формирование результатов (абсолютный и
покатегорийный протоколы, результаты кругов), работу анонимных финишёров и
обработку случая полного завершения гонки.

## Requirements

### Requirement: Фиксация финиша

SHALL Финиш участника фиксируется указанием его имени/номера. Результатом фиксируется
время между стартом участника и моментом финиша. Если участник не стартовал,
фиксация игнорируется. Повторный финиш одного и того же участника игнорируется.

#### Scenario: Успешный финиш

- GIVEN участник стартовал и ещё не финишировал
- WHEN указание его имени и нажатие финиша
- THEN фиксируется его результат с временем, участник получает статус финиша

#### Scenario: Повтор финиша

- GIVEN участник уже в списке финишёров
- WHEN его имя вводится повторно
- THEN повторный финиш игнорируется, к протоколу ничего не добавляется

#### Scenario: Финиш не стартовавшего

- GIVEN участник не стартовал
- WHEN фиксация его финиша
- THEN фиксация игнорируется

### Requirement: Абсолютный протокол

SHALL Система формирует общий список финишёров, отсортированный по времени, для
режима `Разделка` отображается отдельной секцией «Абсолют».

#### Scenario: Расстановка в абсолютном протоколе

- GIVEN несколько финишёров
- WHEN отображается протокол в режиме `Разделка`
- THEN финишёры отображаются упорядочеными по времени

### Requirement: Протокол по категориям

SHALL Финишёры группируются по категориям. Каждая категория
отображается отдельным упорядочанным по времени списоком.

#### Scenario: Группировка по категориям

- GIVEN финишёры из разных категорий
- WHEN отображается протокол
- THEN финишёры разделены по категориям и упорядочены внутри категории

### Requirement: Анонимные финишёры

SHALL Пока гонка идёт, можно зафиксировать анонимного финишёра с системным именем
«Аноним N» и не известным заранее участником. Позже анонима можно переименовать
в известного участника или удалить.

#### Scenario: Добавление анонима

- GIVEN идущая гонка
- WHEN пользователь фиксирует анонимный финиш
- THEN участник добавляется с именем «Аноним N»

#### Scenario: Переименование анонима

- GIVEN существует анонимный финишёр
- WHEN он переименован в известного участника
- THEN его время переносится на этого участника и аноним удаляется из списка

#### Scenario: Удаление анонима

- GIVEN анонимный финишёр в списке
- WHEN он удалён с подтверждением
- THEN участник удаляется из протокола

### Requirement: Режим на круги

SHALL В режиме на круги для участника фиксируется время каждого круга;
окончательное время финиша присваивается только тогда, когда участник проходит
последний круг категории.

#### Scenario: Фиксация круга

- GIVEN участник на промежуточном круге
- WHEN фиксация финиша
- THEN к списку кругов добавляется время круга, итоговое время остаётся
  неопределённым

#### Scenario: Последний круг

- GIVEN участник проходит последний круг своей категории
- WHEN фиксация финиша
- THEN итоговое время присваивается и участник получает статус финиша

### Requirement: Формат отображения времени

SHALL Финишное время отображается в формате `ЧЧ:ММ:СС.ммм` (часы, минуты, секунды,
миллисекунды).

#### Scenario: Форматирование результата

- GIVEN финишёр с фиксированным временем
- WHEN он отображается в протоколе
- THEN время выводится в формате `ЧЧ:ММ:СС.ммм`
