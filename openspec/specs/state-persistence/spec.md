# State Persistence Specification

## Purpose

Определяет сохранение состояния гонки в локальном хранилище браузера,
экспорт состояния в файл JSON, импорт состояния из файла JSON и
восстановление незавершённой гонки при следующем запуске.

## Requirements

### Requirement: Персистентность состояния

SHALL Все ключевые данные гонки (участники, старты, финишёры по категориям, анонимы,
текущий индекс стартования, имя гонки, тип, интервал, время начала/окончания,
круги по категориям, флаги завершённости) сохраняются в локальном
хранилище браузера при каждом изменении.

#### Scenario: Сохранение при изменении

- GIVEN любое состояние гонки изменяется
- WHEN происходит изменение
- THEN актуальное значение сохраняется в локальное хранилище

### Requirement: Восстановление состояния

SHALL При инициализации системы состояние восстанавливается из локального
хранилища, при отсутствии значений используются значения по умолчанию
(например, по умолчанию тип `Разделка`, имя «Название гонки», интервал
30 секунд).

#### Scenario: Значение по умолчанию при отсутствии данных

- GIVEN ключ в локальном хранилище отсутствует
- WHEN состояние восстанавливается
- THEN используется значение по умолчанию этого параметра

### Requirement: Экспорт состояния в JSON

SHALL Доступна операция сохранить гонку: формируется полный снимок состояния и
сохраняется в файл `sync-data.json` для скачивания.

#### Scenario: Выгрузка снимка

- GIVEN гонка в состоянии `PREPARE`
- WHEN пользователь нажимает «Сохранить»
- THEN формируется файл `sync-data.json` со снимком состояния

### Requirement: Импорт состояния из JSON

SHALL В состоянии `PREPARE` пользователь может загрузить существующий файл
JSON и продолжить гонку. Загруженое состояние применяется, а состояние
гонки восстанавливается.

#### Scenario: Загрузка снимка

- GIVEN файл JSON с состоянием в формате
- WHEN пользователь выбирает файл
- THEN состояние применяется и гонки возобновляются

#### Scenario: Небезопасный ввод

- GIVEN в файле отсутствует часть полей
- WHEN выполняется импорт
- THEN недостающие поля заполняются значениями по умолчанию

### Requirement: Продолжение гонки

SHALL Загруженное или ранее сохранённое состояние гонки может быть продолжено:
состояние восстанавливается, а если есть начавшиеся старты — гонка
продолжается в текущем статусе.

#### Scenario: Продолжение незавершенной гонки

- GIVEN загружена гонка с уже стартанными участниками
- WHEN гонка возобновляется
- THEN состояние восстанавливается и управление переходит в статус начальной гонки

### Requirement: Полный сброс

SHALL Пользователь может полностью очистить сохранённое состояние, удалив
все сохранённые данные в локальном хранилище.

#### Scenario: Очистка хранилища

- GIVEN в локальном хранилище есть сохранённое состояние
- WHEN пользователь подтверждает сброс гонки
- THEN всё сохранённое состояние вычищается
