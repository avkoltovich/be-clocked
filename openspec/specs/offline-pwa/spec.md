# Offline PWA Specification

## Purpose

Определяет возможность установки и работы приложения BeClocked в режиме
мобильного PWA (Progressive Web App) без подключения к сети.

## Requirements

### Requirement: Установка как PWA

SHALL Приложение предоставляется как устанавливаемое PWA через web-manifest,
иконки и тему оформления.

#### Scenario: Установка

- GIVEN пользователь открывает приложение
- WHEN приложение устанавливается
- THEN предоставляется иконки, web-manifest, тема оформления, имя «BeClocked»

### Requirement: Кэширование и офлайн-работа

SHALL Приложение кэшируется и работает без интернета через service worker,
загружая необходимые ресурсы.

#### Scenario: Работа офлайн

- GIVEN приложение открыто и установлено
- WHEN пользователь работает офлайн
- THEN приложение доступно и загружает кэшированные ресурсы

### Requirement: Мобильный интерфейс

SHALL Приложение адаптировано для мобильных устройств и использует адаптивную
мобильную тему Taiga UI для отображения гонки и списка участников.

#### Scenario: Отображение на мобильном устройстве

- GIVEN приложение запускается на мобильном устройстве
- WHEN пользователь смотрит на приложение
- THEN отображается мобильный интерфейс с адаптивной темой
