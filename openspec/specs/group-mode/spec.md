# Group Mode Specification

## Purpose

Определяет поведение режима `Групповая` (масс-старт): одновременный старт всех
участников, обобщённый таймер гонки, а также режим на круги с покатегорийным
подчётом количества кругов.

## Requirements

### Requirement: Масс-старт

SHALL В режиме `Групповая` на старте все участники одновременно получают статус
`STARTED`, а время старта фиксируется единым моментом.

#### Scenario: Одновременный старт всех

- GIVEN список участников готов
- WHEN пользователь нажимает «Старт» в режиме `Групповая`
- THEN все участники помечаются стартовавшими, фиксируется единое время старта

### Requirement: Обобщённый таймер

SHALL Во время групповой гонки отображается обобщённое время, прошедшее с момента
старта, в формате `Ч:ММ:СС`.

#### Scenario: Тиканье общего таймера

- GIVEN групповая гонка идёт
- WHEN проходит время
- THEN отображается прошедшее время в формате `Ч:ММ:СС`

### Requirement: Подсчёт кругов по категориям

SHALL Для групповой гонки можно задать количество кругов по каждой категории. По
умолчанием значение равно 1. Гонка считается «на круги», если хотя бы одна
категория имеет значение более 1.

#### Scenario: Настройка кругов по категории

- GIVEN загружены категории участников
- WHEN пользователь задаёт число кругов
- THEN для категории сохраняется заданное количество кругов, по умолчанию 1

#### Scenario: Определение режима на круги

- GIVEN по меньшей мере одна категория имеет количество кругов больше 1
- WHEN отображается панель
- THEN применяется режим на круги с отображением времени по каждому кругу

### Requirement: Остановка групповой гонки

SHALL Групповую гонку можно остановить: участники, оставшиеся на трассе,
автоматически маркируются DNF (did not finish), фиксируется время
завершения, гонка помечается завершённой.

#### Scenario: Снятие участников с трассы

- GIVEN групповая гонка идёт
- WHEN пользователь нажимает «Стоп»
- THEN оставшиеся стартовавшие участники получают статус `DNF`,
  фиксируется время завершения
