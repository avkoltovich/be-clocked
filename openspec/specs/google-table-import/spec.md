# Google Table Import Specification

## Purpose

Определяет импорт участников из Google Таблицы по URL через многошаговую
подстроку: получение данных листа, выбор столбца с именем участника и столбца
с категорией.

## Requirements

### Requirement: Ввод URL Google-таблицы

SHALL Импорт инициируется вводом URL Google Таблицы. Из URL извлекается ID листа для
запроса данных. Поле URL блокируется во время загрузки.

#### Scenario: Извлечение идентификатора

- GIVEN пользователь ввёл корректный URL Google Таблицы
- WHEN инициируется импорт
- THEN ID таблицы извлекается из URL и используется для запроса

#### Scenario: Некорректный URL

- GIVEN пользователь ввёл URL без идентификатора таблицы
- WHEN инициируется импорт
- THEN данные не запрашиваются и действие игнорируется

### Requirement: Загрузка данных листа

SHALL Система запрашивает данные листа по публичному эндпоинту Google
(Sheets gviz) и отображает их. Пошаговый импорт отображается загрузочным
индикатором.

#### Scenario: Успешная загрузка

- GIVEN корректный URL
- WHEN данные успешно получены
- THEN отображаются доступные столбцы и шаги импорта

#### Scenario: Ошибка загрузки

- GIVEN данные не получены
- WHEN загрузка завершается
- THEN отображается уведомление об ошибке проверки URL

### Requirement: Выбор столбца имени

SHALL На втором шаге пользователь выбирает столбец, содержащий фамилию и имя
участника.

#### Scenario: Выбор столбца имени

- GIVEN загружены столбцы
- WHEN выбран столбец имени
- THEN шаг переходит к выбору названия столбца с категориями

### Requirement: Выбор столбца категории

SHALL На третьем шаге пользователь выбирает столбец с категориями. После выбора
импорт завершается.

#### Scenario: Выбор столбца категории

- GIVEN выбран столбец имени
- WHEN выбран столбец категории
- THEN импорт завершается и участники передаются в систему

### Requirement: Формирование участников

SHALL Каждая строка, имеющая имя и категорию, становится участником с
незаполненным стартовым номером и статусом готовности. Строки без имени или
категории пропускаются.

#### Scenario: Импорт валидных строк

- GIVEN строки с именем и категорией
- WHEN импорт завершён
- THEN создаётся участник по строке, с номером null и статусом `READY`

#### Scenario: Пропуск пустых строк

- GIVEN строка без имени или без категории
- WHEN импорт завершён
- THEN пустые строки не становятся участниками
