# ITT Mode Specification

## Purpose

Определяет поведение режима `Разделка` (индивидуальный старт с интервалом):
настройку интервала между стартами, автоматический последовательный старт
участников по таймеру, пропуск участника с отменой, паузу и определение
момента, когда все участники стартовали.

## Requirements

### Requirement: Интервал старта

SHALL В режиме `Разделка` между стартами участников выдерживается интервал (delta) в
секундах. По умолчанию интервал равен 30 секундам. Интервал можно изменить во
время гонки.

#### Scenario: Интервал по умолчанию

- GIVEN режим `Разделка`
- WHEN гонка не настраивалась
- THEN интервал старта равен 30 секундам

#### Scenario: Изменение интервала

- GIVEN гонка идёт
- WHEN пользователь устанавливает новый интервал
- THEN следующий отсчёт использует новый интервал

### Requirement: Таймер стартующего участника

SHALL На панели прогресса отображается отсчёт до старта текущего участника: остаётся
`максимальный интервал − прошедшее время`; по достижении нуля участник
стартовывает.

#### Scenario: Отсчёт до старта

- GIVEN гонка запущена
- WHEN проходит интервал времени
- THEN отсчёт уменьшается и доходит до нуля

### Requirement: Автоматический последовательный старт

SHALL По истечении интервала текущий участник помечается стартовавшим,
фиксируется время его старта, и управление передаётся следующему участнику.
Повторяется до тех пор, пока не стартовал последние участник списка.

#### Scenario: Старт участника по таймеру

- GIVEN интервал истёк для текущего участника
- WHEN таймер обнуляется
- THEN участник получает статус стартования, фиксируется время старта,
  и активным становится следующий участник

#### Scenario: Все участники стартовали

- GIVEN стартовал последний участник списока
- WHEN таймер финишируется
- THEN система помечает, что все участники стартовали

### Requirement: Пропуск участника

SHALL Текущего участника можно пропустить: он получает статус DNS (did not start),
добавляется в список пропущенных и не запускается на старт. Действие можно
отменить.

#### Scenario: Пропуск участника

- GIVEN выбран текущий участник
- WHEN пользователь нажимает «Пропустить»
- THEN участник помечается `DNS`, добавляется в список пропущенных,
  и отображается кнопка отмены

#### Scenario: Отмена пропуска

- GIVEN участник пропущен
- WHEN пользователь нажимает «Вернуть»
- THEN последовательный пропуск отменяется по последнему пропущенному

### Requirement: Пауза гонки

SHALL Идущую гонку можно поставить на паузу: таймер останавливается и отсчёт
интервала сбрасвается. Возобновление возможно с кнопки старта.

#### Scenario: Пауза

- GIVEN идущая гонка в режиме `Разделка`
- WHEN пользователь нажимает «Пауза»
- THEN таймер останавливается, отсчёт сбрасывается, гонка переходит в паузу
