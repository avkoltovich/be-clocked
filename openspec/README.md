# OpenSpec — BeClocked

Данный каталог содержит **спецификацию текущего функционала** приложения
BeClocked (офлайн PWA для контроля старт/финиш-полотоков велогонки). Она
создана по подходу [OpenSpec](https://openspec.dev) как *source of truth*
поведения системы и служит отправной точкой для полного передела
приложения.

## Как читать

- `openspec/specs/<capability>/spec.md` — описание текущего (as-is) поведения
  по каждому функциональному модулю: цели (`## Purpose`) и требования
  (`## Requirements`) с сценариями в формате GIVEN/WHEN/THEN.
- `openspec/config.yaml` — контекст проекта (стек, язык) и правила артефактов.
- `openspec/changes/` — здесь позже появятся *change proposal* (what/how),
  включая сам план переделки. Завершённые изменения архивируются в
  `changes/archive/`.

## Как использовать для переделки

Спеки описывают *что* система делает сейчас (поведение, а не реализацию).
Для планирования переделки создайте change-предложение по схеме `spec-driven`:

```text
/opsx:propose "заменить <модуль> на <новое поведение>"
```

В change-предложении описывайте **дельты** к этим speкам (ADDED / MODIFIED /
REMOVED требования); после внедрения слияние дельт обновит main specs.

## Ограничения as-is

- Временны́е метки хранятся как `Date.now()` (мс с эпохи); интервал — в секундах.
- Хранилище данных — `localStorage` браузера (нет бэкенда/аутентификации).
- Импорт участников только из публичных Google Таблиц (gviz).
- UI завязан на Taiga UI; состояние — на `BehaviorSubject` (RxJS).
